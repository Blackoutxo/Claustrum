<h1 style="text-align: center;">Claustrum</h1>

A privacy focused robust password manager. I created Claustrum to securely and safely store my password even in plain text. I do not trust online password managers as it is online and NOT SECURE however much one can guarantee that it is safe & such. As rate of loss of privacy is growing, Wouldn't it better to have a cross-platform password-manager?

## Overview
Claustrum stores your saved credentials (title + password + tags) in a single encrypted file on disk, unlocked with one master password. Nothing is stored in plaintext except salt on disk, all passwords are encrypted at rest using AES-GCM, with the encryption key derived from your master password via PBKDF2. Here's a guide to use [Claustrum](Guide.md).

## Features
- **Master-password gated:** All the stored passkey and credentials are unlocked by one master-password entry. (One wrong entry loudly crashes the application)
- **AES-256 GCM encryption:** Claustrum uses Aes-256 with GCM generated from masterkey, salt stored to encrypt all the credentials.
- **Material-You (M3) Theme:** Claustrum currently tries to follow the Material you (M3) design layout of pill shaped button, search bar and such.
- **Custom-card based entry list:** A custom painted dynamic card renderer instead of a stamp-paint card renderer.
- **Duplication-entry-detection:** Whenever a repeated entry is added via add key dialog, duplication is detected then asks user for overwriting.
- **File encryption:** Encrypts user selected file containing readable data which is then secured by a separate password for the file that can be read and written via the app.
- **Password Evaluation:** Uses custom password entropy estimation measures to determine password's strength.
- **Password Generation:** Custom password generator to generate strong password when adding entry.
- **Dual theme:** Two themes, Dark and light by switching from settings.
- **Sidebar navigation:** Navigation in sidebar for (Home/Favourite/Evaluation/Files/Settings)
- **Periodic Clipboard clear:** Clears your clipboard periodically.

## Security Model
**What is secured?** 
- Every title, password & tags along with favourite's list is stored with AES-256 encryption.

**What is NOT secured?** 
- `Salt` and `config` file are not secured and for a good reason, salt are just randomly generated bytes to add more to the complexity of encryption.
- config is kept plain as to not burden the system with more encryption and decryption jargon for plain texts that will have minuscule effect on privacy.

**Password strength check**
- Checks every password and gives special focus to Masterkey when it is below the entropy estimation.
